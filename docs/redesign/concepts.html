Building PCF components
with ESBuild

Faster builds are only part of the story. A practical look at ESBuild support, bundle sizes and the tradeoffs.

Oliver Flint   /   28 January 2026   /   PCF

The default build

PCF development cycles can be slow, especially when you are working on a large component. The build process takes time, and waiting for it can interrupt your flow.

The default build uses webpack. Version 1.47.1 of pcf-scripts introduced experimental support for ESBuild. Let's look at how to enable it.

At the time this article was written, ESBuild support was experimental. Check the context before applying it to a current project.

Enable the feature flag

Create a featureconfig.json file alongside your component's package.json and add:

featureconfig.jsonCopy · preview
{
  "pcfUseESBuild": "on"
}

Install the dependency, then compare build times and output sizes for your own component.
